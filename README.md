# Uforiya Website

The official landing page for [Uforiya](https://uforiya.xyz) — the collaboration platform built for music creatives.

## What This Repo Is

This is the public-facing website for Uforiya. It serves as the landing page, waitlist signup, and introduction to what Uforiya is and does. It is separate from the main app and backend.

## Pages

- `index.html` — Main landing page with waitlist signup
- `what-is-uforiya.html` — Detailed explanation of Uforiya's features and vision
- `about.html` — About page

## Tools Used

- **HTML5** — Page structure and content
- **CSS3** — Styling, animations, responsive layout
- **JavaScript** — Starfield canvas animation (`stars.js`)
- **Formspree** — Waitlist email collection (no backend required)
- **GitHub Pages** — Hosting and deployment

## Design

The design follows Uforiya's space/UFO aesthetic — dark backgrounds, purple and cyan accents, and a floating starfield animation. The color palette is built around:

- Background: `#050507`
- Primary accent: `#00F0FF` (cyan)
- Secondary accent: `#7B3FFF` (purple)
- Text: `#B5BDC9`

## Process

The website was built as a simple static site to establish Uforiya's online presence ahead of the app launch. The goal was to communicate what Uforiya is, collect waitlist signups, and reflect the brand aesthetic.

The site is fully responsive and designed to work cleanly on mobile, tablet, and desktop.
